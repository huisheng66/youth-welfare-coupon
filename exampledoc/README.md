# 批量导入示例文件

对应管理端统一导入（上传预检 → 确认执行）的三类名单导入。每类提供 `.csv` / `.xlsx` / `.txt` / `.docx` 四种格式各一份，内容相同，上传时任选其一即可。

| 文件（前缀 × 4 种格式） | 导入入口（管理端） | 用途 | 上传时需填参数 |
| --- | --- | --- | --- |
| `users-用户核验页-批量开通用户账号.*` | 「用户核验」页 → 导入用户名单 | 批量创建青年用户账号，导入即视为核验通过 | 是否发送激活邮件（默认开） |
| `issue-用户核验页-按名单批量发券.*` | 「用户核验」页 → 按名单发券 | 给已有用户按名单批量发券 | 券模板、每人数量（1–10） |
| `points-志愿服务时长页-批量时长入账扣减.*` | 「志愿服务时长」页 → 按名单调整时长 | 批量时长入账 / 扣减 | 默认说明（行内已填说明时优先用行内） |

> 注：`points-*` 第 4 行是对余额为 0 的用户做 `-1` 扣减，按本目录顺序（先导 users 再导 points）执行时必然被「时长余额不足」拦截。这是刻意保留的扣减/拦截演示；如需整份跑通，给该用户先入账即可。

## 各类型列说明

- **users（开通账号）**：姓名（必填）、学号、用户名、手机、邮箱（可选）、组织、备注。
  用户名缺省时依次回退取学号（≥3 位）、手机号（≥5 位）；有邮箱的用户收激活邮件（一次性链接设密码），无邮箱（或关闭通知）的用户在执行结果中获得一次性初始凭证。
- **issue（按名单发券）**：只有一列「用户标识」，填 用户名 / 邮箱 / 手机 / 学号 任一，精确匹配。
- **points（时长入账/扣减）**：用户标识、时长(小时)（支持负数扣减，不能为 0，±100000 以内）、说明（可省略，省略时用界面「默认说明」）。

## 通用规则

- 首行可为表头（系统按关键词识别列，列顺序随意）；无表头时按固定列序解析——users 为：姓名、学号、用户名、手机、组织、备注（注意：无表头时无法提供邮箱列）。
- issue / points 的标识解析优先级：用户名 → 邮箱 → 手机 → 学号；查无此人或歧义（学号多命中）按行报错。
- 同一用户 / 用户名 / 手机 / 邮箱在文件内重复：保留首次出现的行，其余行预检失败。
- 限制：单文件 ≤ 2MB、默认 ≤ 1000 行、单元格 ≤ 512 字符；CSV/TXT 编码 UTF-8 或 GBK 均可（本目录 CSV 带 BOM，Excel 直接打开不乱码）。
- 流程：上传后先预检（不写任何业务数据），确认后逐行执行；失败行可重试，断点续执不会重复入账/发券。
- 示例中的姓名、手机、邮箱均为虚构。实际使用时：issue / points 的用户标识须替换为系统内已存在且核验通过的用户；users 的用户名 / 手机 / 邮箱不得与现有账号重复。
